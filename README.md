
# Real-Time Face Detection using OpenCV

This is a simple Python project that detects human faces in real-time using a webcam and OpenCV's Haar Cascade Classifier.

--> Features
- Real-time video processing.
- Accurate face detection with green bounding boxes.
- Smooth exit using the 'a' key.


## Requirements
Make sure you have Python 3.x installed, then install the dependencies:

```bash
pip install -r requirements.txt
```
